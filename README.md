# MotionBenchMaker 2.0 Leaderboard

The MotionBenchMaker 2.0 Leaderboard provides benchmark results for sampling-based motion planners evaluated across a collection of MotionBenchMaker scenarios.

The leaderboard reports planner performance using metrics such as:

* Success Rate
* Planning Time
* Path Length

Benchmarks are generated using MotionBenchMaker 2.0, a Python-based benchmarking framework built on Pinocchio, Coal, Pink, MeshCat, and OMPL.

## View the Leaderboard

https://adilshiyas.github.io/MotionBenchMaker2.0_Leaderboard/

## Submit a Planner

Anyone can submit their own planners through the leaderboard website for evaluation on supported MotionBenchMaker scenarios.
