# MotionBenchMaker2.0 Leaderboard

This repository hosts a public leaderboard benchmarking and ranking motion planners on selected MotionBenchMaker problems.    
All benchmarks were generated using MotionBenchMaker implemented in the Genesis simulator.  
The leaderboard can be accessed here:      
https://adilshiyas.github.io/MotionBenchMaker2.0_Leaderboard/
